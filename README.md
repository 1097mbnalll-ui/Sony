# ترجمان

تطبيق آيفون يشبك على جهاز PS5 في البيت عن طريق التشغيل عن بُعد (Remote Play)،
يستقبل الصورة مباشرة من الجهاز، ويقرأ نصوص اللعبة ويترجمها للعربي على الجوال
وأنت تلعب على الشاشة عادي. التطبيق يستقبل بس، ما يرسل أي أوامر تحكم.

> غير تابع لشركة Sony. «PlayStation» و«PS5» علامات تجارية لأصحابها.

## المراحل
| المرحلة | المحتوى | الحالة |
|---|---|---|
| 1 | الربط برمز PIN، اكتشاف الجهاز، تشغيله من الراحة، عرض البث | ✅ |
| 2 | تحديد منطقة الحوار، قراءة النص (Apple Vision)، ترجمة أبل المجانية، القراءة بصوت، الواجهة الكاملة | **قيد التجربة** |
| 3 | ترجمة الصوت، سجل الترجمات، تحسين السرعة | لاحقاً |

## بنية المشروع
```
core/            مكتبة C: chiaki-ng (اتصال الشبكة المحلية فقط) + جسر بسيط لـ Swift
  bridge/        trjm.h / trjm.c — الواجهة اللي يستخدمها التطبيق
  stubs/         بدائل لأجزاء اللعب عبر الإنترنت (غير مستخدمة)
  tests/         اختبار دخان يشتغل على لينكس في CI
app/             تطبيق SwiftUI (المشروع يتولد بـ XcodeGen في CI)
third_party/     chiaki-ng كـ submodule مثبّت على إصدار محدد
.github/         البناء والرفع على TestFlight بدون ماك
docs/            الإعداد، وخطة النشر للعامة
```

## البناء
كل شي يصير في GitHub Actions — ما يحتاج ماك. الخطوات في [docs/SETUP.md](docs/SETUP.md).
